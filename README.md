# Modpack Builder

Локальный плагин для Codex, который подбирает Minecraft-моды с CurseForge, проверяет точные версии и обязательные зависимости и экспортирует сборку в ZIP для Prism Launcher. Технический ID плагина — `minecraft-mod-curator`.

## Установка

[Скачайте ZIP из выпуска 0.7.0](https://github.com/IKirillka/modpack-builder/releases/tag/v0.7.0) и распакуйте его или клонируйте репозиторий. Полная инструкция включает установку локального компонента, подключение Codex, браузер для CurseForge и первый запуск. [Инструкция по установке](docs/INSTALL.md)

## Что можно попросить в чате

- «Помоги собрать модпак под Minecraft 1.21.1 и NeoForge. Основная тема — автоматизация на Create».
- «Почему нет Create? Проверь сборку перед экспортом».
- «Экспортируй проверенную ревизию в ZIP для Prism».
- «Покажи настройки автоочистки» или «Покажи корзину».

Состав, ревизии, проверенные планы и кэш фактов сохраняются локально. Экспорт и импорт запускаются отдельными командами. Автоочистка включается по запросу и по умолчанию переносит подходящие задания в корзину. [Управление заданиями](docs/JOB_CLEANUP.md) · [Инструменты MCP](docs/MCP.md)

## Тесты и сборка пакета

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]' 'setuptools>=77' wheel
.venv/bin/python -m pytest -q
.venv/bin/python scripts/build_package.py
```

ZIP и контрольные суммы появятся в `dist/`. Пакет содержит исходники, инструкции и wheel. Python-зависимости загружаются при установке. Локальные данные и отчёты в пакет не входят.
