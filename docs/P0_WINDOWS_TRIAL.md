# Повторная проверка P0 на Windows

Установите актуальный пакет, перезапустите Codex Desktop и откройте новый локальный чат. [Установка через PowerShell](WINDOWS.md).

1. Откройте сохранённую ревизию или начните небольшой **отдельный** тестовый подбор для Minecraft 1.21.1 и NeoForge. Для повторения тестовых фильтров используйте Create с порогом строго выше 1 000 и Performance с порогом строго выше 50 000. В качестве короткого прогона выберите несколько модов из уже сохранённых данных. Если добавляете Modrinth, зафиксируйте ID проекта, ID версии и основание включения.
2. Откройте выделенный браузер через `py -3 -X utf8 .\scripts\start_browser.py`, если локальной установке нужен CDP. Видимую проверку CurseForge выполняйте вручную. Попросите «Проверь ревизию N перед экспортом и сохрани этот запрос в установочном плане». Чат должен вернуть ID проверки, затем текущий проект, цепочку и счётчики. Для короткой проверки ID и счётчики также доступны через CLI:

   ```powershell
   py -3 -X utf8 .\scripts\launch.py preflight "ID_СБОРКИ" --revision 13 --loader-version 21.1.267 --request "Проверка на Windows"
   py -3 -X utf8 .\scripts\launch.py status "ID_ПРОВЕРКИ"
   ```

3. Дождитесь сохранения хотя бы одного ответа и попросите «Останови проверку ID». После статуса `cancelled` попросите «Возобнови проверку ID». CLI для продолжения:

   ```powershell
   py -3 -X utf8 .\scripts\launch.py resume "ID_ПРОВЕРКИ"
   ```

   Сохраняется тот же ID. В прогрессе появляются попадания в контрольные точки. При ошибке источника восстановите доступ и продолжите тот же ID. При исчерпании перебора можно передать `--max-states`.
4. Когда план показывает `ready: true`, попросите явно экспортировать проверенную ревизию. Проверьте путь и SHA‑256 ZIP, имена и хеши файлов в квитанции. Изменившийся или недоступный точный файл блокирует экспорт. Список ручных файлов и требующих подтверждения вложений показывается отдельно.
5. В Prism выберите **Добавить экземпляр → Импорт** и укажите ZIP. Создайте отдельный экземпляр. При предупреждении для Modrinth сравните имена и контрольные суммы с планом перед подтверждением. Если Prism запросит ручное скачивание, добавьте именно файл из плана.
6. Сверьте новый экземпляр через PowerShell:

   ```powershell
   py -3 -X utf8 .\scripts\launch.py verify prism "ID_ЭКСПОРТА" --instance "C:\путь\к\новому\экземпляру"
   ```

   Если сверка отдельно сообщает об отсутствующем LWJGL, откройте в Prism страницу **Версия** только этого экземпляра, дождитесь сохранения компонентов и повторите сверку. Если состояние не обновилось, перезапустите Prism и откройте эту же страницу.

   Ожидайте пустые списки `missing`, `extra`, `different` и `unverified`, а также совпадение компонентов Minecraft и NeoForge. Полные пути указаны в `report_path` и `receipt_path`. Для вызова из чата зарегистрируйте отдельный каталог как локальный псевдоним назначения и используйте `verify_prism_export` с этим псевдонимом. Зарегистрировать папку можно командой `py -3 -X utf8 .\scripts\launch.py init --destination "$instance" --alias prism-test`.
7. Отдельно зафиксируйте запуск до меню, открытие мира и проверку игровых механик, если они были разрешены и выполнены. Успешная сверка JAR оставляет эти этапы в статусе `untested`.

## Правка одноразового тестового экземпляра

Закройте тестовый экземпляр и Prism перед изменениями. Импортируйте следующую ревизию как **отдельный** экземпляр. В командах ниже `ID_СТАРОГО_ЭКСПОРТА` и `ID_НОВОГО_ЭКСПОРТА` — ID фоновых задач экспорта.

```powershell
py -3 -X utf8 .\scripts\launch.py instance-update register "$instance" "ID_СТАРОГО_ЭКСПОРТА"
py -3 -X utf8 .\scripts\launch.py instance-update preview "$instance" "ID_НОВОГО_ЭКСПОРТА" "$staged"
py -3 -X utf8 .\scripts\launch.py instance-update apply "$instance" "ID_НОВОГО_ЭКСПОРТА" "$staged" --confirm "$token"
py -3 -X utf8 .\scripts\launch.py instance-update rollback "$instance" "$backup" --confirm "$token"
```

`preview` выводит добавления, удаления, замены и файлы, которые будут перемещены в резервную копию. `apply` проверяет токен повторно, сверяет результат и возвращает `rollback_directory`. Для отката используйте этот путь как `$backup` и тот же токен. Версию Minecraft и загрузчика меняйте отдельным импортом.
