### Случаи метаданных

- **ImmediatelyFast.** В журнале сохранены индексы 0 и 1, 20 и 6 строк из 26. Эти данные воспроизведены. Для второго допустимого формата использовано смещение 0 и 20 с теми же сохранёнными границами. Архив содержит вывод диагностики, полного HTML этих двух страниц в нём нет.
- **Structures Arise.** Сохранённый файл `9232207` требует Create Fabric и Fabric API. В отдельном разрешении выбран `6354819`. План сохраняет обе версии и причину выбора.
- **Create: Escalated.** У точного файла `8679269` CurseForge объявляет Create Fabric. В сохранённом JAR-снимке у Escalated указан Create в диапазоне `[6.0.7,6.1.0)` и необязательный Sable. Расхождение блокирует план, пока к конкретному файлу не добавлено подтверждённое решение. Расхождение в источниках и решение видны в отчёте.
- **JEI, Xaero’s World Map, MezzConfig.** Проверены отдельные дополнительные требования из документации автора, сохранённые в аудите. У сохранённого JEI 19.69.0.457 зафиксированы зависимости MezzConfig и ограничение Minecraft `[1.21, 1.21.1)`, которое исключает 1.21.1 при статической проверке. Снимок MezzConfig не содержит разрешённого mod ID. Исторический импорт сам по себе эти расхождения не разрешает.
- **Vintage и KubeJS Create.** В сохранённых декларациях Vintage есть необязательный KubeJS. Краш-репорт отдельно указывает на класс KubeJS Create. Это условие можно записать явным свидетельством для точного файла при наличии KubeJS. Статическая проверка читает декларации, а работа интеграции проверяется в запущенной игре.
- **Диапазоны и вложения.** Проверены случаи Radars с суффиксом игры, диапазон Rhino с номером сборки и отличие Maven-рекомендации от точного диапазона. По Jar-in-Jar проверяются координаты и пересечение диапазонов. Если источник не позволяет определить выбранное вложение, отчёт содержит отдельное непроверенное условие. [Версии Maven](https://maven.apache.org/pom.html#dependency-version-requirement-specification) · [Метаданные NeoForge](https://docs.neoforged.net/docs/1.21.1/gettingstarted/modfiles/) · [Jar-in-Jar](https://docs.neoforged.net/toolchain/docs/dependencies/jarinjar/)

## Реальный импорт в Prism 11.1.1 на Linux

Через стандартный MCP-клиент проверены живой ответ Modrinth для CC:Tweaked `2jhB1Ii4`, метаданные загрузчика Prism, экспорт ZIP и SHA‑512 вложения. Сценарий занял 6,56 с до готового ZIP. Для смешанного прогона выбран точный FerriteCore CurseForge `429235/7524151` из сохранённого ответа и тот же CC:Tweaked с живого Modrinth. Предпроверка заняла 1,64 с, экспорт — 3,25 с.

В отдельном корне Prism импортирован смешанный ZIP. Prism запросил подтверждение вложения CC:Tweaked и скачал FerriteCore через CurseForge. Экземпляр создан через 8,9 с после команды импорта, включая ожидание подтверждения. На первом снимке оба JAR уже совпадали, а компонент LWJGL отсутствовал в сохранённой конфигурации. Открытие страницы **Версия** тестового экземпляра после повторного открытия Prism привело к штатному разрешению LWJGL 3.3.3. Повторная сверка прошла. На отдельной копии тестового экземпляра также проверены предпросмотр добавления FerriteCore, применение, сверка и откат.

| Этап смешанной проверки | Результат |
| --- | --- |
| План | Готов по сохранённым метаданным CurseForge и живому Modrinth |
| ZIP | Создан и проверен, конкретные файлы зафиксированы |
| Импорт | Создан отдельный экземпляр Prism |
| Сверка JAR | 2 из 2 совпали. Нет лишних, отсутствующих, изменившихся или непроверенных файлов |
| Компоненты | Minecraft 1.21.1, NeoForge 21.1.267, LWJGL 3.3.3 после штатного разрешения в Prism |
| Главное меню, мир, механики | Не проверялись |

В Windows Codex Desktop и Prism 0.8.0 в этой среде не проверялись. [Шаги прогона на Windows](P0_WINDOWS_TRIAL.md).

## Отчёты и связь данных

- `installation-plan.json` хранит исходный запрос, ревизию, точные файлы, причины включения и метаданные.
- `installation-receipt.json` связывает запрос, ревизию, ID проверки, SHA‑256 ZIP и снимок экземпляра. Плагин также сохраняет квитанцию и снимки в SQLite.
- `prism-import-verification.json` содержит результаты сверки и раздельные статусы компонентов, импорта и игровых этапов.
- Архивное сравнение обнаружило **232 против 231**. Лишний файл — `Chunky-NeoForge-1.4.23.jar`. Время появления неизвестно. Ранний список содержит имена, фактический снимок — имена и SHA‑256. Сверка не приписывает старому списку отсутствующие хеши.
